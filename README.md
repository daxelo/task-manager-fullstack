# Task Manager

Application web de gestion de tâches réalisée avec React, Node.js, Express et PostgreSQL.

Ce projet m'a permis de mettre en pratique le développement Full Stack, notamment la création d'une API REST et la communication entre le frontend, le backend et une base de données.

## Fonctionnalités

- Ajouter, modifier et supprimer des tâches
- Changer le statut et définir une priorité
- Rechercher et filtrer les tâches
- Consulter les statistiques des tâches
- Enregistrer les données dans PostgreSQL

## Technologies utilisées

- **Frontend :** React, JavaScript, CSS
- **Backend :** Node.js, Express
- **Base de données :** PostgreSQL
- **Versioning :** Git, GitHub

## Lancer le projet

Installer les dépendances dans les dossiers `frontend` et `backend` avec `npm install`.

Configurer la connexion PostgreSQL dans `backend/.env` et préparer la table `tasks`.

Démarrer ensuite chaque partie avec :

```bash
npm run dev
```
